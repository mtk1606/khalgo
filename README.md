# Atelier Algo

Cours interactif de Programmation 1 en français, adapté du support AlgoBCG (BCG S3, 2025/2026).

- 12 leçons couvrant les variables, entrées/sorties, conditions et boucles
- Visualisations et organigrammes interactifs
- 9 laboratoires de pseudo-code avec 26 cas de test visibles et traces des variables
- Partiel et examen final avec corrections
- Progression locale et sauvegarde JSON

## GitHub Pages

Dans **Settings → Pages → Build and deployment**, choisir **Deploy from a branch**, puis **main** et **/ (root)**, et enregistrer. Aucun build ni dépendance requis.

Les cinq fichiers du site doivent rester ensemble à la racine. `.nojekyll` désactive le traitement Jekyll. Les chemins relatifs fonctionnent sous le chemin de projet GitHub Pages.

## Exécution et données

Le laboratoire interprète le pseudo-code français dans le navigateur ; ce n’est pas un compilateur Python ou C++. Limite de 3 000 étapes pour interrompre les boucles infinies. Les tests sont finis et visibles ; les réponses rédigées restent autoévaluées. Brouillons et progression sont conservés dans le navigateur, sans synchronisation entre appareils.

## Validation

26 cas de référence réussis. Chaque programme de départ volontairement erroné échoue à au moins un test. Vérifications des types, des variables non initialisées, de la division par zéro et de la limite de boucle. Navigation, exécution, traces et correction du partiel vérifiées dans le navigateur.

## Source pédagogique

Support : AlgoBCG.pdf, Pr. Jihane Alami Chentoufi, Programmation 1, BCG S3, 2025/2026. Les schémas sont redessinés. Les ambiguïtés du support concernant XOR et le tarif à 20 copies sont signalées et expliquées dans les leçons.
